# Suggested Meaningful Git Commit History (B4)

Create the public repository early enough to show iterative development. Suggested commits:

1. `chore: initialize CIA3 repository structure and dataset citation`
2. `feat: add transaction cleaning and RFM feature engineering`
3. `feat: add PCA and k-means customer segmentation`
4. `feat: add MANOVA and Hotelling T2 inference`
5. `feat: add prospective churn labeling and LDA evaluation`
6. `feat: add Streamlit dashboard and CSV download`
7. `docs: add final results, assumptions, figures, and AI disclosure`

Do not create fake backdated commits. Make normal commits as you review and adapt the code.
