# GitHub Student Developer Pack / SDK Evidence (B2)

This repository is prepared to demonstrate a GitHub Student Developer Pack workflow, but account activation cannot be fabricated. Complete these steps with your own GitHub account:

1. Verify/activate the GitHub Student Developer Pack.
2. Capture a screenshot showing the active Student status/benefit page.
3. Use **GitHub Codespaces** for at least one reproducible run of this project.
4. In Codespaces: `pip install -r requirements.txt`, then `streamlit run streamlit_app.py --server.address 0.0.0.0 --server.port 8501`.
5. Set port 8501 visibility to Public while demonstrating the app.
6. Capture a screenshot of the running Codespace/app and save it as `GitHub_SDK_Codespaces_Evidence.png`.

README documentation already explains this integration.
