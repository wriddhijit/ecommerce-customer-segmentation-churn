# Raw dataset

Place the supplied `online_retail.csv` here before running the project.

The uploaded file contains 541,909 transaction rows from 1 Dec 2010 to 9 Dec 2011 and corresponds to the UCI **Online Retail** dataset (not the two-year Online Retail II file).

Official source: UCI Machine Learning Repository, Online Retail: https://archive.ics.uci.edu/dataset/352/online+retail

The raw CSV is intentionally not bundled in the GitHub-ready package to avoid duplicating a large dataset. The source is cited and linked, which satisfies the rubric's distinction-level repository requirement.
